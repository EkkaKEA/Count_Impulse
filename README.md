# Count_Impulse

Подсчет импульсов — тестовое задание.

## Условие

Реализовать программу подсчета импульсов в среде TIA Portal на языке SCL.

Реализовать обработку `N > 0` (`INT`, константа) счётчиков. Количество счётчиков должно меняться только изменением значения `N`. Все счетчики имеют индивидуальный набор параметров.

## Параметры счётчика

### Входные параметры

| Параметр         | Тип      | Описание                                                         |
|------------------|----------|------------------------------------------------------------------|
| Управляющий сигнал | `BOOL` | По заднему фронту увеличиваем значение счётчика на 1             |
| `Min`            | `INT`    | Начальное значение счета                                         |
| `Max`            | `INT`    | Максимальное значение счета                                      |

### Выходные параметры

| Параметр                | Тип      | Описание                     |
|-------------------------|----------|------------------------------|
| Текущее значение счётчика | `INT`  | Текущее значение             |

## Управление

- При нажатии кнопки **Старт** все счетчики переходят в режим счета.
- Для остановки счета используется кнопка **Стоп**.
- При нажатии кнопки **Сброс** все счетчики должны быть сброшены.
- При достижении максимального значения счётчик сбрасывается, выдается импульс переполнения секундной длины на соответствующий выход, и счетчик продолжает считать с `0`.

## Компоненты

### Входы (Inputs)

| Вход | Описание                                                         | Тип контакта    |
|------|------------------------------------------------------------------|-----------------|
| `I1` | Кнопка «Старт»                                                   | Замыкающий      |
| `I2` | Кнопка «Стоп»                                                    | Замыкающий      |
| `I3` | Кнопка «Сброс»                                                   | Замыкающий      |
| `IN` | Имитатор, выдающий импульсы с определенной частотой               | Замыкающий      |

> Сигнал для импульсов можно брать, например, из `Clock memory byte`.

### Выходы (Outputs)

| Выход | Описание                      |
|-------|-------------------------------|
| `Q1`  | Переполнение счетчика 1        |
| `Q2`  | Переполнение счетчика 2        |
| `QN`  | Переполнение счетчика N        |
